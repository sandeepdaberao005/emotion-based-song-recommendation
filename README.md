# 📌 Project Overview

Traditional music recommendation systems rely on user history and preferences but fail to consider a user's real-time emotional state.

This project solves that problem by combining:

✅ Facial Expression Recognition

✅ NLP-Based Sentiment Analysis

✅ AI Chatbot Integration

✅ Deep Learning Models

✅ Personalized Song Recommendations

The system detects emotions from either webcam facial expressions or user text input and recommends songs that match the user's current mood.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/emotion-based-song-recommendation.git
```

### Move to Project Folder

```bash
cd emotion-based-song-recommendation
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
